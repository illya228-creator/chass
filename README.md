# Шахматы на Python и Pygame

Учебный проект шахматной игры на Python с использованием Pygame Community Edition (`pygame-ce`). Проект разделён на четыре основных Python-модуля и использует PNG-изображения шахматных фигур.

<img width="799" height="798" alt="изображение" src="https://github.com/user-attachments/assets/a82dc448-6926-4172-8ab3-dce7dab29e74" />


## Возможности

- Шахматная доска 8×8 с чередованием цветов клеток
- Белые и чёрные фигуры из PNG-файлов
- Выбор и перемещение фигур мышью
- Базовые правила движения пешки, ладьи, коня, слона, ферзя и короля
- Превращение пешки в ферзя
- Чередование ходов белых и чёрных
- Базовое сообщение об окончании игры, если один из королей отсутствует на доске

## Требования

- Установленный Python
- Библиотека `pygame-ce`

Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

В файле `requirements.txt` должна быть строка:

```text
pygame-ce
```

## Запуск игры

Откройте терминал в папке проекта и выполните:

```bash
python main.py
```

Если используется виртуальное окружение, сначала активируйте его.

## Назначение модулей

- **`main.py`** — запускает Pygame, обрабатывает действия мыши, управляет очередностью ходов и основным игровым циклом.
- **`board.py`** — содержит настройки окна, загружает изображения фигур и рисует доску и фигуры.
- **`pieces.py`** — создаёт начальную расстановку, перемещает фигуры и превращает пешку в ферзя.
- **`game_logic.py`** — проверяет базовые правила движения, наличие препятствий на пути и текущее условие победы.

## Названия изображений фигур

Названия файлов состоят из двух букв:

- `w` — белая фигура
- `b` — чёрная фигура
- `p` — пешка
- `r` — ладья
- `n` — конь
- `b` — слон
- `q` — ферзь
- `k` — король

Например, `wn.png` — белый конь, а `bk.png` — чёрный король. Имена файлов должны совпадать с названиями, указанными в `board.py`.

## Текущие ограничения

Это учебный прототип, а не полностью реализованный шахматный движок. В текущей версии ещё не реализованы:

- Проверка шаха и мата
- Запрет ходов, оставляющих собственного короля под шахом
- Рокировка
- Взятие на проходе
- Правила ничьей, включая пат и повторение позиции
- Полная проверка легальности всех ходов

Сейчас окончание партии определяется по наличию королей на доске. Эти ограничения нужно устранить, прежде чем считать игру полноценной шахматной реализацией.
